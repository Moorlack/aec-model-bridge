# AEC Revit: Analyze Model

Confirm the document and analysis scope: categories, levels, selected elements, relevant views, and linked models. Use typed warning, clash, quantity, schedule, room/material, link, and targeted read tools appropriate to that scope.

Present clear findings in tables: issue or category, affected IDs/counts, location or level where available, and a practical next action. For quantities, state units and totals; for a large result set, show a useful subset and the full count. Do not repair warnings or clashes automatically: change the model only after the user authorizes a defined remediation.
