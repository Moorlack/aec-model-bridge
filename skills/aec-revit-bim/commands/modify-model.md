# Modify model

Use this playbook for changing, copying, moving, replacing, or deleting existing model content.

1. Resolve the target by selected elements, IDs, category/type queries, parameters, or geometry. Inspect current values before changing them.
2. State the affected count, scope, and intended result. For deletion or broad filters, exclude unrelated, pinned, and linked content unless explicitly included.
3. Prefer typed change tools: parameter setters, type change/replace, transform/copy, material setter, grouping tools, or deletion tools.
4. When scope is explicit, execute without repetitive element-by-element confirmation. When a destructive or broad scope remains uncertain, ask for a single confirmation of that scope.
5. Verify the result through element properties, geometry, list queries, or a snapshot delta. Report cascading deletion or partial failures truthfully.

Use approval-plan tools only when required by server policy or helpful for a reversible multi-step change.
