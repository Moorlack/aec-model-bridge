# Units and coordinates

AEC tool schemas may use different conventions by operation and version. Inspect the selected live tool before sending geometry; preserve explicit user units and state conversions where ambiguity matters. Do not silently interpret bare architectural dimensions as mm, m, or ft.

Confirm project origin, level, and orientation before absolute placement. Use X/Y for the plan and Z for elevation. State both endpoints for a line, validate closed profiles for floors/roofs, and confirm host-wall conventions before placing openings.
