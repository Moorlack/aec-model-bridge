# Building design sequence

Start with the brief, open-document health, existing levels/grids, and loaded types. Then author in order: levels and grids; foundations/columns/beams where needed; exterior walls and partitions; doors/windows; floors and roof; rooms and MEP; views, sections, dimensions, tags, schedules, sheets, and exports. Verify every major phase before continuing; create one representative object first when geometry or hosting is uncertain.
