# MEP workflows

Confirm document, level, existing architecture/structure, and loaded types before routing. Use `revit_create_duct`, `revit_create_pipe`, and `revit_create_conduit` for native runs, and family placement for compatible equipment/fixtures. Define endpoints, level, elevation/offset, size, and system/type from the live schema. Verify one route segment before scaling, then check clashes and report quantities/schedules as requested. Linked models are coordination context, not editable content, unless explicitly included.
